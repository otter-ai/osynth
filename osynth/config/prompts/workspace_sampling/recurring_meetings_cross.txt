Generate ONLY cross-functional and external-facing recurring meetings:
- Cross-team project sync meetings (multiple teams collaborating on a project)
- External-facing meetings when external people exist (client calls, partner check-ins, vendor reviews)
- Cross-departmental rituals (e.g., product/engineering/design weekly)

Do NOT generate company-wide meetings (all-hands) or per-team rituals (1x1s, standups, team syncs) — those are handled separately.

The meeting_type field is free-form — use descriptive labels like "project_sync", "client_call", "sales_discovery", "customer_success_checkin", "vendor_review", "cross_team_sync", etc.

For each meeting, also provide structured labels:
- affiliation: "intra_team", "cross_team", "cross_department", "org_external", or "ambiguous"
- participant_count: "3+", "2", "single_speaker", or "primary_with_audience"
- purpose: "training", "routine_monitoring", "problem_solving", or "information_giving"
- topic: free-form topic category
- roles: list of participant roles in this meeting context

Constraints:
- No person should have overlapping recurring meetings at the same time
- All meeting times must be within working hours and end before working hours end
- Use realistic durations: project syncs 30-60min, external calls 30-60min
- External participants should usually appear only in external-facing meeting types

Output a single JSON object:
{
  "recurring_meetings": [
    {
      "id": "rm_cross_1",
      "title": "Customer Success Sync",
      "meeting_type": "customer_success_checkin",
      "organizer_id": "p1",
      "attendee_ids": ["p1", "p2", "ext1"],
      "cadence": "weekly",
      "day_of_week": 1,
      "time_of_day": "10:00",
      "duration_minutes": 30,
      "description": "Weekly customer check-in",
      "labels": {
        "affiliation": "org_external",
        "participant_count": "3+",
        "purpose": "routine_monitoring",
        "topic": "Customer Success",
        "roles": ["account_manager", "customer"]
      }
    }
  ]
}

Valid cadence values: "daily", "weekly", "biweekly", "monthly"
For "daily" cadence, day_of_week should be null.
For "weekly"/"biweekly", day_of_week is 0=Monday through 4=Friday.
For "monthly", day_of_week represents the preferred weekday.
