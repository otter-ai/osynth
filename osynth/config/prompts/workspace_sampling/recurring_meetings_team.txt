Generate ONLY this team's local recurring rituals:
- 1x1s between this team's manager and each direct report (weekly)
- This team's standup or weekly sync
- This team's planning / retro rituals if natural for the team's function

Do NOT generate company-wide meetings (all-hands, exec sync) or cross-functional / external meetings.

The meeting_type field is free-form — use descriptive labels like "1x1", "team_standup", "team_weekly", "sprint_planning", "sprint_retro", "design_review", etc.

For each meeting, also provide structured labels:
- affiliation: "intra_team", "cross_team", "cross_department", "org_external", or "ambiguous"
- participant_count: "3+", "2", "single_speaker", or "primary_with_audience"
- purpose: "training", "routine_monitoring", "problem_solving", or "information_giving"
- topic: free-form topic category
- roles: list of participant roles in this meeting context

Constraints:
- All `attendee_ids` must be members of this team (or its manager)
- No person should have overlapping recurring meetings at the same time
- All meeting times must be within working hours and end before working hours end
- Use realistic durations: standups 15-30min, 1x1s 30min, team meetings 30-60min
- Keep total team-local time reasonable

Output a single JSON object:
{
  "recurring_meetings": [
    {
      "id": "rm_{{TEAM_ID}}_1",
      "title": "Engineering Standup",
      "meeting_type": "team_standup",
      "organizer_id": "p1",
      "attendee_ids": ["p1", "p2", "p3"],
      "cadence": "daily",
      "day_of_week": null,
      "time_of_day": "09:30",
      "duration_minutes": 15,
      "description": "Daily standup for the engineering team",
      "labels": {
        "affiliation": "intra_team",
        "participant_count": "3+",
        "purpose": "routine_monitoring",
        "topic": "Software Development",
        "roles": ["engineering_manager", "engineer"]
      }
    }
  ]
}

Valid cadence values: "daily", "weekly", "biweekly", "monthly"
For "daily" cadence, day_of_week should be null.
For "weekly"/"biweekly", day_of_week is 0=Monday through 4=Friday.
For "monthly", day_of_week represents the preferred weekday.
